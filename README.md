# Fornello

A cinematic, scroll-driven landing page for a wood-fired pizzeria.
Bilingual (Persian with right-to-left layout, and English) with a dark and a light theme.

## Stack

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4 · Jest and Testing Library

## Getting started

```bash
npm install
npm run dev        # http://localhost:3000 redirects to /fa or /en
npm run typecheck  # TypeScript
npm test           # unit and component tests
npm run build      # production build
```
